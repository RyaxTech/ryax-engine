{{- if .Release.IsInstall }}

Your initial admin account. Unless you supplied one, the password was generated
for this installation and these two commands are where to read it:

  kubectl -n {{ .Release.Namespace }} get secret {{ .Values.authorization.adminSecret }} -o jsonpath='{.data.admin-user}' | base64 -d; echo
  kubectl -n {{ .Release.Namespace }} get secret {{ .Values.authorization.adminSecret }} -o jsonpath='{.data.admin-password}' | base64 -d; echo

Change it from Users in the web interface once you are in. The secret is not
updated when you do.
{{- end }}
