# API reference

This is the HTTP API used by the Ryax web interface and the `ryaxctl` command line.
The version it documents is shown in the header below.

The document is generated from the service sources at every release, so you can point a
client generator straight at it:
[ryax-spec.json](https://docs.ryax.tech/reference/ryax-spec.json).
